# BIGNOSE OS

ศูนย์ควบคุม AI agent ในเครื่องสำหรับ Claude และ Codex ที่ตอบคำถามสำคัญให้ผู้ใช้ได้ทันทีว่า:

1. ตอนนี้เกิดอะไรขึ้น
2. ทำไมจึงสำคัญ
3. ควรทำอะไรต่ออย่างปลอดภัย

หน้า Dashboard ของ BIGNOSE OS ใช้ภาษาไทย มีสัญญาณหลักเพียงหนึ่งรายการ วงโคจรงานแบบวงกลม เส้น polyline แสดงความสัมพันธ์ และ inspector สำหรับอ่านหรือคัดลอกบริบท โดยไม่สั่งให้ agent ทำงานเอง

## สิ่งที่โปรเจกต์ช่วยผู้ใช้

- เห็นงานที่ติดขัด งานที่กำลังทำ และสิ่งที่ต้องตอบก่อน โดยไม่ต้องอ่าน log ยาว ๆ
- แยกหลักฐานจาก Claude และ Codex อย่างชัดเจน
- เปิดดูรายละเอียดงานย่อยและคัดลอกคำตอบหรือบริบทที่แนะนำได้
- สำรวจ Second Brain จากโครงสร้าง `.claude` และ `.codex` แบบอ่านอย่างเดียว
- ใช้งานได้ทั้งเดสก์ท็อปและมือถือ โดยกราฟยังมีพื้นที่และซูม/เลื่อนตามมุมมองที่รองรับ

## Second Brain: ใช้เพื่อกลับมาทำงานต่ออย่างมีหลักฐาน

Second Brain ช่วยรวบรวม **บริบทที่ระบบอ่านได้ในเครื่อง** จาก `.claude` และ `.codex` ให้กลับมาใช้งานง่ายขึ้น โดยไม่ได้สั่ง agent หรือแก้ไขไฟล์แทนคุณ เหมาะกับการตอบคำถามง่าย ๆ ว่า “ค้างตรงไหน”, “มีอะไรใหม่”, และ “จะส่งบริบทให้ Claude หรือ Codex อ่านต่ออย่างไร”

### วิธีใช้ Second Brain

1. เปิด [Second Brain](http://127.0.0.1:4317/#brain) แล้วเลือกงานจาก **วันนี้**, รายละเอียด หรือแผนที่
2. แท็บ **ทำงานต่อ**: กด `ทำงานต่อจากตรงนี้` เพื่อดูสถานะ การตัดสินใจ สิ่งที่ต้องใส่ใจ งานถัดไป และพาธอ้างอิง แล้วเลือก `คัดลอกให้ Claude` หรือ `คัดลอกให้ Codex` เพื่อนำ brief ที่มีหลักฐานไปวางเอง
3. แท็บ **กล่องเข้า**: เปิดดูรายการที่เพิ่งเข้าดัชนี ไฟล์ที่ยังไม่ถูกจัดประเภท และคำสั่งที่อาจเปลี่ยนไป กด `ตรวจแล้ว` เมื่อตรวจเสร็จ หรือคัดลอกพาธ/แม่แบบ frontmatter ไปใช้เอง
4. แท็บ **ถาม Brain**: พิมพ์คำถามสั้น ๆ และเลือก Claude, Codex หรือทั้งหมด ระบบค้นหาดัชนีในเครื่องแบบกำหนดผลลัพธ์ พร้อมพาธอ้างอิงของทุกผลลัพธ์ ไม่ได้สร้างคำตอบด้วย AI ระยะไกล
5. แท็บ **Claude ↔ Codex**: ตรวจรายการที่ *ควรตรวจสอบ* ว่าความรู้อาจมีอยู่ฝั่งหนึ่งแต่ยังไม่พบอีกฝั่ง หรือบริบทอาจต่างกัน ใช้เป็นข้อเสนอแนะสำหรับคนตรวจ ไม่ใช่ข้อสรุปหรือการซิงก์
6. ในแผนที่ ใช้ `1 ชั้น` เพื่อดูชั้นที่ติดกับจุดที่เลือก หรือ `2 ชั้น` เพื่อเปิดบริบทรอบถัดไปแบบจำกัด ชั้นที่สองจะแสดงเบากว่า แต่ศูนย์กลางและจุดยึด Claude/Codex ชั้นแรกยังคงที่
7. ใช้ `− ย่อ`, ปุ่มเปอร์เซ็นต์สำหรับรีเซ็ต และ `+ ขยาย` เพื่อปรับแผนที่ตั้งแต่ 70–140% ครั้งละ 10%; บนมือถือให้เลื่อนดูภายในพื้นที่กราฟโดยหน้าเว็บไม่ล้นออกด้านข้าง

แผนที่เป็นโลกวงกลมขนาดคงที่ภายในพื้นที่เลื่อนของตัวเองบนหน้าจอแคบ จึงยังอ่านความสัมพันธ์ได้โดยไม่บีบเป็นรายการแนวตั้ง และจะแสดงโหนดโครงสร้างได้สูงสุด 40 โหนดในครั้งเดียว ไม่ใช่การทำดัชนีหรือแสดงทุกไฟล์ในเครื่อง

### ขอบเขตความปลอดภัยของ Second Brain

- ใช้บน `127.0.0.1` เท่านั้น อ่านเฉพาะราก `.claude` และ `.codex` ที่ระบบอนุญาตแบบอ่านอย่างเดียว และไม่ต้องใช้ API key
- ไม่ส่งความรู้ไปยังเครือข่าย: โดยเฉพาะ **ถาม Brain** เป็นการค้นหาเชิงกำหนดผลลัพธ์จากดัชนีในเครื่อง ไม่เรียก remote LLM และไม่สร้างคำตอบแบบ AI
- ไม่มีการสั่งรันงาน เปิด/แก้ไข/ลบ/ย้ายไฟล์ต้นทาง จัดประเภทให้เอง เผยแพร่ข้อมูล หรือซิงก์ Claude กับ Codex อัตโนมัติ
- `รีเฟรช` จะอ่านแหล่ง `.claude` และ `.codex` ในเครื่องที่ได้รับอนุญาตอีกครั้ง เพื่อสร้างเฉพาะดัชนี Brain ในหน่วยความจำใหม่ ไม่รับพาธจากผู้ใช้ ไม่เปลี่ยนไฟล์ต้นทาง และไม่ซิงก์ผู้ให้บริการ
- ปุ่มคัดลอกเขียนข้อความลง clipboard เฉพาะเมื่อเบราว์เซอร์อนุญาตเท่านั้น; หากใช้ไม่ได้ หน้าจอและข้อมูลอื่นยังทำงานต่อได้
- เบราว์เซอร์จดจำเพียงเวลา `lastSeenBuiltAt` แบบตัวเลขหนึ่งค่าเมื่อกด `ตรวจแล้ว`; การซ่อน Gap มีผลแค่เซสชันปัจจุบัน และไม่มีเนื้อหาความรู้ถูกบันทึกโดยฟีเจอร์นี้

## ความปลอดภัยโดยค่าเริ่มต้น

- ทำงานบน `127.0.0.1` และไม่ควรเปิดพอร์ตสู่สาธารณะ
- โหมดเริ่มต้นคือ `viewer`
- การสั่งรันถูกปิด (`executionEnabled: false`)
- `POST /api/run` ปฏิเสธคำขอใน viewer mode
- ตัวจัดทำดัชนี Second Brain ในเครื่องอาจอ่าน Markdown จากราก `.claude` และ `.codex` ที่ได้รับอนุญาต แต่เบราว์เซอร์ได้รับเฉพาะฟิลด์สรุปที่มีขอบเขตและผ่านการปกปิดข้อมูลแล้ว; ไฟล์ต้นทางจะไม่ถูกแก้ไข
- การรีเฟรช Second Brain อ่านแหล่ง `.claude` และ `.codex` ที่ได้รับอนุญาตอีกครั้งเพื่อสร้าง cache ดัชนีในหน่วยความจำใหม่ โดยไม่แก้ไขไฟล์ต้นทางหรือซิงก์ผู้ให้บริการ
- Semantic Brain นับเฉพาะความรู้ที่ตั้งใจเก็บ โดยไม่รวม plugin, cache, marketplace, ไฟล์ชั่วคราว หรือ checkbox จากคู่มือ
- Checkbox จะกลายเป็นงานเมื่อไฟล์เปิดใช้ `semantic.extract_tasks: true` อย่างชัดเจนเท่านั้น
- ไม่ต้องใช้ API key สำหรับการเปิดดู Dashboard

## เริ่มใช้งาน

ต้องใช้ Node.js 20 ขึ้นไป

```bash
git clone https://github.com/Boom-Vitt/bignose-os.git
cd bignose-os
npm install
npm start
```

จากนั้นเปิด:

- Dashboard: [http://127.0.0.1:4317/](http://127.0.0.1:4317/)
- Second Brain: [http://127.0.0.1:4317/#brain](http://127.0.0.1:4317/#brain)

ตรวจสถานะระบบ:

```bash
curl http://127.0.0.1:4317/api/health
```

ผลที่ปลอดภัยควรระบุ `mode: "viewer"` และ `executionEnabled: false`

## โครงสร้างหลัก

```text
public/     Dashboard, Second Brain, CSS และ assets
server/     local API, scanner, catalog, jobs และ safety gates
hooks/      การเชื่อมเหตุการณ์จาก agent ในเครื่อง
scripts/    เครื่องมือประกอบสำหรับตรวจ provider
test/       source artifacts สำหรับตรวจพฤติกรรมและขอบเขตความปลอดภัย
docs/       คู่มือการเชื่อมต่อและ hooks
```

เอกสารสถาปัตยกรรมหลักอยู่ใน [DESIGN.md](DESIGN.md) และขอบเขตข้อมูล/ความปลอดภัยอยู่ใน [CONTRACT.md](CONTRACT.md)

## ข้อมูลส่วนตัว

Repository แบบ Public นี้มีเฉพาะ source code คู่มือ และชุดข้อมูลจำลองสำหรับนักพัฒนา ไม่รวมข้อมูลจริงระดับรากจาก `.claude/`, `.codex/`, environment files, log, output, browser artifacts หรือข้อมูล SDD ในเครื่อง โดยไฟล์ใต้ `test/fixtures/project/.claude/` เป็นข้อมูลสังเคราะห์สำหรับอธิบายโครงสร้างเท่านั้น เมื่อติดตั้ง BIGNOSE OS จะอ่านเฉพาะข้อมูลจากเครื่องของผู้ใช้คนนั้นตามขอบเขต local read-only และจะไม่ดาวน์โหลดหรือซิงก์ข้อมูลส่วนตัวของผู้พัฒนา

อย่า commit credential, session, local memory หรือ screenshot ที่มีบริบทงานส่วนตัว หากพบปัญหาความปลอดภัย โปรดอ่าน [SECURITY.md](SECURITY.md)
